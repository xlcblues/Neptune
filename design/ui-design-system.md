# Neptune UI 设计系统

## 1. 品牌与 Logo

### 1.1 设计概念

Neptune 取自海王星与海神尼普顿。Logo 采用极简几何语言，只保留一个符号：

- **三叉戟形均衡器**：三根粗细一致的圆角立柱，中轴最高并带尖锐戟尖，既是海神权杖，也是音乐频谱；
- **底部一条轻弧线**：把三根立柱连起来，暗示声波与正在播放；
- 无装饰、无渐变、无星球插画，单色扁平，大量留白，缩到 16px 依然清晰。

主色为 Neptune Blue `#2B5BE8`，浅色背景使用 `#4D8DFF`，深色背景使用白色符号。

### 1.2 Logo 文件

| 文件 | 用途 |
| --- | --- |
| `assets/logo/neptune-mark.svg` | 应用图标（纯色圆角方块 + 极简声波三叉戟） |
| `assets/logo/neptune-symbol.svg` | 透明符号，用于侧边栏、空态、页眉 |
| `assets/logo/neptune-wordmark.svg` | 符号 + “Neptune” 字标，用于启动画面/安装器 |
| `assets/logo/neptune-mark.png` / `neptune-icon-256.png` | 预览与窗口图标 |

### 1.3 使用规范

- 深色背景使用白色/近白符号；浅色背景使用 `#4D8DFF` 单色符号；
- 安全间距：符号四周至少保留符号高度 25% 的空白；
- 最小尺寸：16px（仅符号），48px（含字标）；
- 不使用其他颜色替换主色，不拉伸变形，不加阴影与渐变外框。

## 2. 设计理念

设计关键词：**深海静谧、玻璃质感、流动音乐**。

界面遵循苹果式原则：

- 响应即时：按钮按下瞬间反馈，不等待松开；
- 材质分层：侧边栏、工具栏、播放条使用不同透明度与模糊强度的玻璃；
- 一切可打断：弹窗、面板、卡片动效使用弹性物理，随时可反向；
- 克制高级：信息密度高但留白充足，主色只用于关键操作与正在播放状态。

## 3. 色彩体系（深色主题为主）

## 4. 字体与排版

字体栈：`Segoe UI Variable Display, Segoe UI Variable, Segoe UI, Inter, -apple-system, sans-serif`。

| 名称 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 28-32px | 600 | 1.1 | 页面大标题 |
| H1 | 22px | 600 | 1.2 | 区块标题 |
| H2 | 17px | 600 | 1.25 | 卡片标题 |
| Body | 14px | 400 | 1.5 | 常规正文 |
| Caption | 12px | 400 | 1.4 | 辅助信息 |
| Micro | 11px | 500 | 1.3 | 标签、时间戳 |

规则：字母间距为 0；数字使用等宽数字样式保证进度时间对齐；正文不缩小到 11px 以下。

## 5. 布局与间距

- 4pt 网格：4 / 8 / 12 / 16 / 24 / 32 / 48；
- 窗口结构：左侧导航 240px，内容区自适应，底部播放条 96px；
- 卡片圆角 8px，头像/封面 8px，按钮 8px，胶囊标签 999px；
- 内容区横向 padding 24px，区块间距 32px；
- 列表行高 56px，封面 48px，稳定尺寸避免悬停抖动。

## 6. 动效规范

| 场景 | 参数 | 说明 |
| --- | --- | --- |
| 默认 UI 动效 | 弹性，阻尼 1.0，响应 0.3-0.4s | 面板、切换、浮层 |
| 手势/甩动 | 阻尼 0.8，响应 0.4s，带速度继承 | 列表、滑杆、抽屉 |
| 按钮按下 | 100ms scale 0.97 | 按下即反馈 |
| 播放条进度 | 线性 200ms | 跳转时平滑过渡 |
| 特效入场 | 淡入 + 轻微上浮 | 不抢内容注意力 |
| Reduced Motion | 仅 200ms 淡入淡出 | 尊重系统设置 |

所有动效必须可打断：动画永远从当前屏幕值继续，不用固定结束态硬切。

## 7. 组件规范

- **导航项**：高 36px，圆角 8px，图标 18px + 文本，选中态 `bg-3` + 左侧 3px 主色条；
- **图标按钮**：36x36px 固定尺寸，悬停 `bg-2`，按下 scale 0.97，带 tooltip；
- **播放按钮**：44px 圆形，主色渐变填充，白图标；
- **滑杆**：轨道 4px 圆角，进度主色渐变，拖拽点 14px 白色 + 阴影；
- **流派标签**：胶囊，`rgba(255,255,255,0.08)` 底，文字 11px，可带流派色圆点；
- **曲目卡片**：封面 8px 圆角 + 标题/艺人两行，悬停上浮 1px 并显示播放浮层；
- **播放条**：96px，`glass-strong` 材质 + `blur(32px)`；三栏布局：当前曲目（封面 56px + 标题/艺人）、控制与进度、右侧工具（特效、音量、队列）。
- **播放控制**：上一首/下一首 32px 图标按钮；主播放按钮 44px 圆形主色渐变；进度滑杆自适应，时间戳使用等宽数字。
- **音量交互**：静音按钮 32px，音量滑杆 90px，宽度窄于 980px 时隐藏滑杆、保留静音按钮。
- **队列浮层**：320px，从播放条右上角上弹，最大高度 `min(400px, 55vh)`，列表行内显示序号、标题、艺人与当前播放均衡器动画。
- **快捷键**：空格播放/暂停，左右方向键跳转 ±10s，系统媒体键播放/暂停/上一首/下一首。

## 8. 播放特效清单

| 特效 | 视觉特征 | 技术实现 |
| --- | --- | --- |
| 频谱极光 | 底部频谱 + 顶部淡紫色极光流动 | Canvas 2D + AnalyserNode |
| 脉冲光谱 | 圆形频谱环随节拍脉动 | Canvas 2D |
| 波形镜面 | 实时波形 + 垂直镜像倒影 | Canvas 2D |
| 黑胶唱片 | 封面旋转 + 唱臂 + 唱片纹 | CSS transform + Web Audio |
| 粒子声场 | 粒子随频率上下漂移并连线 | Canvas 2D |
| 动态封面 | 封面放大 + 主色流光渐变 | Canvas/WebGL |

所有特效共享 AnalyserNode 数据，切换特效不中断播放。

## 9. 无障碍与响应式

- 全部交互支持键盘：空格播放/暂停、方向键跳转、Tab 可见焦点；
- 支持 `prefers-reduced-motion` 与 `prefers-reduced-transparency`；
- 最小对比度：正文 4.5:1，大标题 3:1；
- 窗口最小宽度 960px；窄窗口下侧边栏可折叠为图标栏；
- 深色主题为默认，浅色主题可选并跟随系统。
